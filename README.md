# POLS 081 · SSQL Workshop Lab

The Part 2 lab handout for the SSQL data workshop in POLS 081, *Global Environmental Governance* (Swarthmore College, Fall 2026): summary statistics, one figure and one statistical test, in R and Quarto.

Workshop website: <https://gamusu.github.io/pols081-ssql-workshop/>

## Open in Posit Cloud (no installation needed)

1. Go to **<https://posit.cloud>** and log in (a free account works).
2. Click **New Project → New Project from Git Repository**, paste this repository's URL, and click **OK**.
3. In the **Files** pane, open **`setup.R`** and click **Source**. Wait until the packages finish installing (a few minutes).
4. Open **`lab-handout.qmd`** and click **Render**. You'll get `lab-handout.pdf`.

## Open on your laptop

1. Click the green **Code** button on this page, then **Download ZIP**.
2. **Unzip** the file. On Windows, right-click it and choose **Extract All…** (don't work inside the zip).
3. Double-click **`pols081-ssql-lab.Rproj`** to open the folder in RStudio.
4. If you haven't installed the packages yet, open `setup.R` and click **Source**. Then open `lab-handout.qmd` and click **Render**.

## What's here

| File | What it is |
|:---|:---|
| `lab-handout.qmd` | The lab handout: Example 1 (worked), Example 2 (you fill in the code), Workshop Questions |
| `data/` | The datasets used in the handout and the workshop's visualization guide |
| `bib/lab.bib` | References for the handout |
| `setup.R` | Installs the R packages the handout needs |
